Import formats

What Church Slides can bring into your library

Moving from another app? If ProPresenter, FreeShow, OpenLP or OpenSong is on the same computer, open the Library, choose Import, and pick it at the top of the list. Your songs and recent services come across together, and nothing in the other app is changed.

Song files

Library → Import → Song files or A whole folder, or drop files onto the Library.

  • PDF chord sheets, including SongSelect lead sheets
  • ChordPro (.cho, .chopro, .chordpro, .pro) and OnSong (.onsong)
  • OpenLyrics (.xml) — what OpenLP, Worship Extreme and others export
  • OpenSong song files
  • CCLI SongSelect downloads (.usr and .txt)
  • Plain text — lyrics, or chords over lyrics, with section names like “Verse 1” and “Chorus”

From other presentation apps

ProPresenter

  • On the same computer: Import → From ProPresenter (version 22 and later).
  • Otherwise: in ProPresenter choose File → Export → Presentation… (a .pro file per song) or Playlist… (.proplaylist — songs and running order together), then import the files.
  • Older versions: File → Export → Text gives an Export.txt with the whole library.

FreeShow

On the same computer: Import → From FreeShow, with your projects as services.

OpenLP

  • On the same computer: Import → From OpenLP.
  • Service files (.osz) import as a service with their songs. Songs exported as OpenLyrics import too.

OpenSong

On the same computer: Import → From OpenSong, with your sets as services. Song files import directly.

EasyWorship, Proclaim and others

Export your songs as text or OpenLyrics if the app offers it, and import those files. Proclaim doesn’t export songs; if they came from SongSelect, download them from SongSelect again.

Something it can’t read?

Connect an AI assistant (Settings → AI → AI assistants) and ask it to read the file into your library — it can open nearly any format and adds songs through Church Slides’ own tools, so they arrive tidy and without duplicates.

Then tell us what the file was, with Send feedback in the app, so the next import just works.
