# Trademarks

The code is MIT-licensed: use it, change it, and ship it, including
commercially. The name **Church Slides** and its logo (in `brand/`) aren't
covered by the code licence. They identify the official app, so that a church
downloading "Church Slides" gets the build this project signs and supports.

You may:

- say your app is "based on Church Slides" or "a fork of Church Slides";
- use the name to refer to this project, in articles, talks, and
  documentation;
- run unmodified official builds anywhere.

Please don't:

- publish a modified build, or a service, under the name Church Slides or
  with its logo;
- use a name or logo that's easy to confuse with it;
- suggest that this project endorses your product.

For your own build, change the name and icons (`src-tauri/tauri.conf.json`,
`src-tauri/icons/`), the bundle identifier, and the update endpoints and key
(only this project can sign updates for the official app).
